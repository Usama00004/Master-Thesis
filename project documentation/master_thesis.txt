\chapter*{Abstract}
% SAMPLE TEXT -- replace the final sentences with your actual findings.
Feature construction is an important component of data mining and machine
learning because the representation of data can substantially influence the
performance and interpretability of predictive models. Traditional feature
engineering commonly depends on manual analysis and domain expertise, which can
make the process time-consuming and difficult to scale.

This thesis investigates whether large language model (LLM) agents can support
feature construction by generating candidate features from structured
datasets. The study develops a prompt-driven framework in which an LLM receives
information about a dataset, proposes feature transformations, and produces
candidate features that can subsequently be evaluated using statistical and
machine learning methods. The generated features are compared with a baseline
based on conventional feature engineering.

The experimental study uses the Default of Credit Card Clients dataset as a
case study. Different prompting strategies are investigated to examine their
effect on the relevance, interpretability, and predictive usefulness of
generated features. The evaluation considers standard classification metrics
including accuracy, precision, recall, F1-score, and ROC-AUC, together with
feature-level analysis.

\chapter{Introduction}

\section{Background}
Feature engineering plays a central role in data mining and machine learning.
The quality of the representation provided to a learning algorithm can affect
both predictive performance and interpretability. Conventional feature
engineering frequently requires domain expertise and manual experimentation,
particularly when useful relationships are not directly represented by the
original variables.

Recent developments in large language models have created opportunities to
support analytical tasks that traditionally required substantial human
reasoning. Because LLMs can interpret natural-language descriptions and
structured information, they provide a potential mechanism for generating
candidate transformations of existing variables.

This thesis investigates the use of LLM agents for feature construction. Rather
than treating the LLM only as a text-generation system, the proposed approach
uses it as a component of an experimental data mining workflow. The objective
is to determine whether LLM-generated features can provide useful information
for downstream machine learning models.

\section{Problem Statement}
Traditional feature construction can be time-consuming and strongly dependent
on the experience of the data scientist. Although automated feature engineering
methods can reduce manual effort, they may provide limited semantic
interpretability or require task-specific configuration.

The research problem addressed in this thesis is therefore how LLM agents can
be used to support the generation of meaningful features while maintaining a
systematic and evaluable process.

\section{Research Aim}
The main aim of this thesis is to investigate the ability of LLM agents to
support feature construction in data mining tasks through prompt-driven
feature generation.

\section{Research Objectives}
The research has the following objectives:

\begin{enumerate}
    \item Investigate the role of feature construction in machine learning.
    \item Design an LLM-based approach for generating candidate features.
    \item Develop and compare different prompt strategies.
    \item Evaluate generated features using statistical and machine learning
          based criteria.
    \item Compare LLM-generated features with conventionally engineered
          features.
    \item Analyse the interpretability, relevance, consistency, and limitations
          of LLM-generated features.
\end{enumerate}

\section{Research Questions}
The study is structured around the following research questions:

\begin{enumerate}
    \item \textbf{RQ1:} To what extent can LLM agents generate meaningful
          features for structured data mining tasks?
    \item \textbf{RQ2:} How does prompt design influence the quality and
          usefulness of LLM-generated features?
    \item \textbf{RQ3:} Do LLM-generated features improve the predictive
          performance of machine learning models compared with a baseline?
    \item \textbf{RQ4:} How interpretable and consistent are the features
          generated by an LLM agent?
\end{enumerate}

\section{Scope of the Study}
The research focuses on structured tabular data and classification-oriented
data mining. The primary case study is the Default of Credit Card Clients
dataset. The work focuses on feature construction rather than developing a
fully autonomous end-to-end machine learning system.

\section{Contributions}
The expected contributions of this thesis are:

\begin{itemize}
    \item an experimental framework for LLM-assisted feature construction;
    \item a set of prompt strategies for candidate feature generation;
    \item an evaluation procedure combining feature-level and model-level
          analysis;
    \item a comparison between LLM-generated and conventional features; and
    \item an analysis of the strengths and limitations of LLM agents in this
          setting.
\end{itemize}

\section{Thesis Structure}
Chapter 2 presents the theoretical background and relevant concepts. Chapter 3
reviews related research on feature engineering, automated feature
construction, and LLM-based approaches. Chapter 4 describes the proposed
methodology and system architecture. Chapter 5 presents the dataset and data
preparation process. Chapter 6 describes the experimental setup and evaluation
strategy. Chapter 7 presents the experimental results. Chapter 8 discusses the
results and research questions. Chapter 9 concludes the thesis and presents
limitations and future research directions.

\chapter{Theoretical Background}

\section{Feature Engineering and Feature Construction}
Feature engineering refers to the process of transforming raw variables into
representations that are more suitable for machine learning algorithms.
Feature construction is a related process in which new variables are derived
from existing attributes.

Examples include ratios, differences, aggregations, interactions, counts, and
temporal summaries. For a dataset containing a bill amount $B$ and a payment
amount $P$, for example, a payment ratio can be defined as

\begin{equation}
    R = \frac{P}{B + \epsilon},
\end{equation}

where $\epsilon$ is a small constant used to avoid division by zero.

Such transformations can expose relationships that are not directly visible
in the original variables.

\section{Automated Feature Engineering}
Automated feature engineering aims to reduce the manual effort required to
construct useful variables. Existing approaches may rely on predefined
transformation libraries, search procedures, symbolic methods, or automated
machine learning systems.

The main challenge is balancing the number of generated candidates with their
quality, computational cost, redundancy, and interpretability.

\section{Large Language Models}
Large language models are neural models trained on large collections of text
and capable of generating and transforming natural language. Their ability to
follow instructions and reason over contextual information makes them
potentially useful for tasks that require semantic interpretation.

In this thesis, the LLM is used to interpret dataset metadata and propose
candidate feature transformations rather than directly replacing the machine
learning model.

\section{Prompt Engineering}
Prompt engineering refers to the design of instructions provided to an LLM.
For feature construction, prompts can specify the dataset schema, variable
types, target variable, desired transformation types, constraints, and output
format.

The experiments in this thesis treat prompt design as an experimental
condition. This makes it possible to examine whether changes in instructions
produce differences in generated feature quality.

\section{LLM Agents}
An LLM agent can be understood as an LLM-based component embedded within a
workflow in which it receives information, performs a reasoning or generation
step, and produces an output that is used by subsequent components.

For this thesis, the agent is organized around the feature construction task:
dataset information is provided as input, candidate features are generated,
the candidates are validated, and selected features are integrated into the
machine learning pipeline.

\section{Experimental Conditions}
The experiments compare at least two major conditions:

\begin{enumerate}
    \item original/baseline feature set;
    \item baseline plus LLM-generated features.
\end{enumerate}

Additional prompt variants can be evaluated as separate experimental
conditions.

\section{Evaluation Metrics}
For classification, the following metrics are considered:

\subsection{Accuracy}
Accuracy measures the proportion of correctly classified observations.

\begin{equation}
Accuracy = \frac{TP + TN}{TP + TN + FP + FN}.
\end{equation}

\subsection{Precision}
Precision measures the proportion of predicted positive cases that are
actually positive.

\begin{equation}
Precision = \frac{TP}{TP + FP}.
\end{equation}

\subsection{Recall}
Recall measures the proportion of actual positive cases correctly identified.

\begin{equation}
Recall = \frac{TP}{TP + FN}.
\end{equation}

\subsection{F1-Score}
The F1-score is the harmonic mean of precision and recall.

\begin{equation}
F1 = 2 \times \frac{Precision \times Recall}
{Precision + Recall}.
\end{equation}

\subsection{ROC-AUC}
ROC-AUC is used to assess the ability of a classifier to discriminate between
the classes across different decision thresholds.

\section{Feature-Level Evaluation}
Generated features are also evaluated independently of model performance.
The analysis considers:

\begin{itemize}
    \item relevance to the target task;
    \item interpretability;
    \item consistency across runs;
    \item redundancy with existing variables;
    \item computational feasibility; and
    \item validity of the proposed transformation.
\end{itemize}

\section{Reproducibility}
The implementation should record the dataset version, preprocessing
configuration, prompt version, LLM configuration, generated feature definitions,
random seeds, model parameters, and evaluation results.

\section{Implications}
If supported by the experimental results, LLM-assisted feature construction
could reduce part of the manual effort involved in exploratory feature
engineering. However, the LLM should be considered an assistant rather than a
replacement for validation because generated transformations can be redundant,
invalid, or inappropriate for a particular modelling task.

\section{Limitations}
Potential limitations include dependence on the selected dataset, sensitivity
to prompt wording, stochastic variation between LLM runs, computational and
API costs, possible hallucinated transformations, and the difficulty of
measuring feature usefulness independently from the downstream model.

\chapter{Conclusion and Future Work}

\section{Conclusion}
This thesis investigated the use of LLM agents to support feature construction
in data mining tasks. The proposed approach integrates prompt-driven candidate
feature generation with conventional data preprocessing, validation, and
machine learning evaluation.

The study is designed to evaluate both the practical usefulness and the
interpretability of LLM-generated features. By comparing LLM-enhanced feature
sets with a conventional baseline, the research provides an experimental basis
for assessing whether LLMs can contribute to feature engineering workflows.

Future research could investigate additional datasets and domains, alternative
LLM models, more advanced agent architectures, iterative feedback loops, and
human-in-the-loop validation. Further work could also explore automated feature
selection, redundancy reduction, cost-aware generation, and integration with
larger-scale machine learning pipelines.
